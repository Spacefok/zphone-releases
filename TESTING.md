# Проверка Zphone Preview

Тестовая версия устанавливается отдельно. Действующие приложения и доступы
не удаляйте. Для подключения понадобится ручное одобрение администратора.

## Установка

1. Откройте релиз v0.3.8 и скачайте файл для своего устройства:
   `Zphone-Preview-0.3.8-windows-x64-setup.exe` или
   `Zphone-Preview-0.3.8-arm64.apk`.
2. Windows: установите Preview в отдельную папку. На последнем шаге есть
   флажки запуска и добавления ярлыка. Приложение запрашивает права
   администратора при запуске. Установщик пока не имеет
   подписи Authenticode; сверяйте источник и контрольную сумму, не отключайте
   защиту Windows целиком.
3. Android: установите APK, разрешив установку только приложению, которым
   открываете файл. После установки разрешение можно выключить.

## Вход

1. В Zphone Preview откройте «Аккаунт» → «Войти через Telegram».
   При первом запуске без подключений этот раздел откроется сразу.
2. Откроется @Zphone_test_bot. Нажмите «Запустить» и сверьте шестизначный номер
   в боте с номером в приложении. Не подтверждайте чужой номер.
3. Дождитесь решения администратора. Вернитесь в приложение и нажмите
   «Проверить одобрение», затем «Получить подключения».
4. Появятся Германия и пять протоколов. Для второго устройства повторите вход:
   каждому устройству нужен отдельный доступ и отдельное одобрение.

Заявка действует 10 минут. Если она истекла, начните вход заново.
Просто сообщение /start без перехода из приложения не создаёт заявку на доступ.
Повторно открыть ту же заявку можно кнопкой «Открыть бота».
При ошибке входа сохраните архив через «Помощь» → «Экспорт диагностики».

## Обновление

1. До включения VPN в Preview откройте «Настройки» → «Проверить обновления».
2. Скачайте и установите предложенную новую версию. Windows покажет мастер установки;
   Android попросит системное подтверждение. Приложение удалять не нужно.
3. После запуска проверьте версию, сохранённый вход, пять подключений и тему.
4. Автопроверка и автозагрузка настраиваются отдельно. Установка всегда
   запускается вручную и блокируется, пока VPN самого Preview включён.
5. Важное или экстренное обновление появится на главном экране после проверки.
   Этот баннер не отключает VPN. Значимость задаётся подписанным описанием релиза.

Автозапуск Windows и запуск в трее остаются отдельными настройками. При
автозапуске появится стандартный запрос UAC, его нужно подтвердить вручную.

## Подключения

1. Самостоятельно выключите другой VPN на тестируемом устройстве.
2. Windows: в настройках выберите режим «VPN», а не «Тестовый».
3. На главном экране выберите Германию и по очереди TrustTunnel, Mieru,
   NaiveProxy, AmneziaWG, Hysteria 2. Перед сменой протокола отключайтесь.
4. Для каждого откройте несколько сайтов, проверьте внешний IP и короткое видео.
   Отметьте сеть (Wi-Fi или мобильная), время и результат. Прогон Android
   повторите на мобильной сети. Hysteria 2 отдельно проверяйте без второго VPN.
5. Проверьте также автоматический выбор протокола.

При сбое нажмите «Помощь» → «Отметить сбой». После проверки экспортируйте
диагностику и отправьте архив администратору лично. Не публикуйте журналы,
профили или ключи в публичном репозитории.

Выход из аккаунта отзывает сессию выдачи профилей, но не удаляет уже выданные
серверные ключи. Для полного отзыва доступа обращайтесь к администратору.
